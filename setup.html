ОТ ФАЙЛОВ К ПЕЧАТНЫМ ПОРТРЕТАМ

Подготовка и запуск

Все три фотографии, файл распознавания и аудиозаписи уже добавлены. Подписи: Кулагина Анастасия, Барсукова и Гладких Макар. Аудио извлечено из предоставленных MP4. Ниже — порядок работы, обновления материалов и публикации сайта.

Посетитель сначала открывает ссылку на этот сайт, нажимает «Навести камеру» и разрешает доступ. Затем сайт распознаёт печатную фотографию и открывает её аудиостраницу. Обычная камера телефона сама по себе этот сайт не запускает.

1. Установите порядок портретов

Используйте порядок изображений при компиляции targets.mind. Первое изображение имеет индекс 0, второе — 1, третье — 2. Номера страниц и аудиофайлов начинаются с 1.

Если порядок неизвестен, сверьте его в компиляторе. Если восстановить его нельзя, снова скомпилируйте те же три фотографии в известном порядке. Сайт не может определить имена людей из файла распознавания.

2. Добавьте четыре файла

  1. Поместите targets.mind в assets/targets/.
  2. Поместите три MP3 в assets/audio/ с именами из таблицы. Проверьте соответствие портретам.
  3. Используйте строчные буквы и точные имена. В Проводнике включите показ расширений, чтобы не получить targets.mind.mind или portrait-1.mp3.mp3.

Если запись имеет формат M4A, WAV или другой формат, сначала экспортируйте её в MP3. Простое переименование расширения не меняет формат. Исходные фотографии не нужно загружать на сайт: для распознавания используется targets.mind. Печатная фотография должна соответствовать изображению, использованному при компиляции.

3. Бесплатно опубликуйте через GitHub Pages

  1. Войдите на GitHub. Создайте новый репозиторий с именем portrait-audio, выберите Public и включите создание README.
  2. В репозитории выберите Add file → Upload files. Перетащите содержимое папки сайта: index.html, setup.html, папки assets и portraits, README и остальные файлы. Завершите загрузку кнопкой Commit changes.
  3. Убедитесь, что index.html лежит в корне репозитория, а не внутри ещё одной папки. Проверьте наличие всех четырёх ваших файлов. Пустые папки GitHub не сохраняет.
  4. Откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root). Нажмите Save.
  5. Дождитесь завершения публикации. На странице Pages появится ссылка Visit site. Откройте именно её; адрес репозитория сайт не заменяет. Используйте HTTPS. Если доступен переключатель Enforce HTTPS, включите его.

Для публичного репозитория GitHub Pages доступен на бесплатном тарифе. Отдельный сервер и платный домен не нужны. Загруженные материалы и прямые ссылки на аудио будут общедоступны. Для этого проекта не нужны ключи API, база данных или сборка.

4. Проверьте со смартфона

  1. Откройте опубликованный HTTPS-адрес в Safari на iPhone или Chrome на Android. Во встроенном браузере мессенджера лучше выбрать «Открыть в браузере».
  2. На главной должны быть доступны четыре файла. Откройте каждую аудиостраницу вручную, нажмите Play и проверьте запись и перемотку.
  3. Вернитесь на главную, нажмите «Навести камеру» и разрешите доступ. При первом запуске дождитесь подготовки.
  4. Наведите камеру на первый портрет. Откроется страница 1; включите звук вручную. Повторите для второго и третьего портрета.
  5. Повторите при освещении и на расстоянии, которые будут у посетителей. Держите в кадре один портрет целиком, без бликов. Если изображения распознаются плохо, проверьте совпадение с оригиналом и резкость печати.

Локальный просмотр на компьютере

Если установлен Node.js, откройте терминал в папке сайта и выполните node preview.mjs. Откройте http://localhost:8080/. Остановка сервера — Ctrl+C. Двойной щелчок по HTML не запускает веб-сервер.

Адрес localhost относится к тому устройству, на котором он открыт. Для проверки со смартфона используйте опубликованный HTTPS-сайт. HTTP-адрес компьютера в локальной сети обычно не разрешает доступ к камере.

Если что-то не работает

  • Файл не найден. Проверьте путь, регистр букв, расширение и завершение публикации; обновите страницу.
  • Камера недоступна. Используйте HTTPS, разрешите камеру в настройках сайта, закройте другие приложения с камерой и попробуйте отдельный браузер.
  • Файл содержит не три изображения. Соберите один targets.mind ровно из трёх нужных портретов.
  • Открылось другое аудио. Порядок записей не совпадает с порядком при компиляции. Переставьте записи, сохранив имена из таблицы, и опубликуйте изменения.
  • Портрет не узнаётся. Уберите блики, измените расстояние, покажите фотографию целиком. MindAR распознаёт изображение по визуальным деталям, а не личность человека. Однотонные, размытые или очень похожие портреты могут распознаваться ненадёжно.
  • Нет звука. Нажмите Play, проверьте громкость и реальный формат файла. Используйте ссылку «Открыть аудиофайл отдельно».

Официальные инструкции: MindAR, компилятор изображений, GitHub Pages, HTTPS на GitHub Pages.
