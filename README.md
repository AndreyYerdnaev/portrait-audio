# Портреты — аудиоистории

Готовый статический сайт на MindAR для трёх печатных фотографий. Все предоставленные материалы добавлены. В MP4 находился звук AAC; из него подготовлены настоящие MP3 для HTML5-аудиоплееров.

| Индекс MindAR | Портрет | Страница | Запись | Длительность |
|---|---|---|---|---|
| 0 | Кулагина Анастасия | `portraits/1.html` | `assets/audio/portrait-1.mp3` | около 5,35 с |
| 1 | Барсукова | `portraits/2.html` | `assets/audio/portrait-2.mp3` | около 6,55 с |
| 2 | Гладких Макар | `portraits/3.html` | `assets/audio/portrait-3.mp3` | около 5,61 с |

Для второго портрета сохранена подпись «Барсукова» по указанию владельца. Биографии и другие личные сведения не добавлены.

## Как посетителю пользоваться сайтом

1. Откройте опубликованный HTTPS-адрес сайта в Safari на iPhone или Chrome на Android.
2. Нажмите «Навести камеру» и разрешите доступ к камере.
3. Покажите одну печатную фотографию целиком, без бликов. При первом запуске дождитесь подготовки распознавания.
4. После распознавания откроется соответствующая страница. Камера остановится.
5. Нажмите Play в плеере. Запуск звука происходит вручную; доступны перемотка и прямое открытие MP3.
6. Чтобы распознать другой портрет, вернитесь на главную и снова нажмите кнопку камеры.

Можно также открыть любую аудиостраницу вручную по карточке с фотографией. Обычная камера телефона самостоятельно сайт не запускает: сначала посетитель открывает ссылку на сайт. QR-коды возле портретов не требуются.

## Соответствие изображений

Файл `assets/targets/targets.mind` содержит ровно три цели формата MindAR v2. Их порядок проверен по размерам и сравнению изображения внутри данных отслеживания с исходными фотографиями:

1. 1086 × 1448 — Кулагина Анастасия.
2. 768 × 1024 — Барсукова.
3. 640 × 960 — Гладких Макар.

Для печати используйте те же фотографии целиком, без дополнительного кадрирования. Копии исходных JPEG сохранены в `assets/images/`. MindAR распознаёт изображение по визуальным деталям, а не личность человека.

## Структура

- `index.html` — главная, проверка материалов и сканер.
- `portraits/1.html`, `2.html`, `3.html` — индивидуальные страницы с фотографиями и плеерами.
- `setup.html` — инструкция и помощь в браузере.
- `assets/catalog.js` — подписи и соответствие индексов страницам и MP3.
- `assets/scanner.js` — запуск MindAR, переходы, обработка ошибок и остановка камеры.
- `assets/player.js`, `files.js`, `styles.css` — аудио, проверка доступности и оформление.
- `assets/targets/targets.mind` — предоставленный файл распознавания, без изменений.
- `assets/audio/` — три MP3, извлечённые из предоставленных MP4.
- `assets/images/` — предоставленные JPEG, без изменений.
- `assets/vendor/` — A-Frame 1.6.0, MindAR 1.2.5 и лицензии.
- `preview.mjs` — необязательный локальный сервер, не требуется для публикации.
- `THIRD-PARTY.md` — источники и версии библиотек.
- `ПРОВЕРКА.md` — результаты проверки и её границы.
- `.nojekyll` — обычная статическая публикация.

## Бесплатная публикация GitHub Pages

1. Файлы сайта должны находиться в публичном репозитории. `index.html` — в его корне.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**.
4. Нажмите **Save** и дождитесь завершения публикации.
5. Откройте появившуюся ссылку **Visit site** по HTTPS. Если доступен пункт **Enforce HTTPS**, включите его.

GitHub Pages доступен бесплатно для публичных репозиториев. Материалы сайта и прямые ссылки на аудио общедоступны. Не нужны ключи API, база данных, сборка, платный домен или подписка MindAR. Относительные пути поддерживают размещение в подпапке проекта.

## Замена записей или портретов

Чтобы заменить запись, замените соответствующий MP3 в `assets/audio/`, сохранив имя файла, и опубликуйте изменение. Не меняйте расширение файла другого формата на MP3: сначала конвертируйте его.

Чтобы изменить печатное изображение, повторно скомпилируйте **все три фотографии в том же порядке** в [компиляторе MindAR](https://hiukim.github.io/mind-ar-js-doc/tools/compile/), замените `targets.mind` и JPEG в `assets/images/`. При изменении подписей обновите `catalog.js`, карточки главной и соответствующую страницу портрета.

Если добавляете четвёртый портрет, требуется изменение списка целей и страниц: этот проект намеренно проверяет наличие ровно трёх целей.

## Просмотр локально

Если установлен [Node.js](https://nodejs.org/), откройте терминал в папке сайта и выполните:

```sh
node preview.mjs
```

Откройте [http://localhost:8080/](http://localhost:8080/) на том же компьютере. Остановка сервера — Ctrl+C. Устанавливать npm-пакеты не нужно. Двойной щелчок по HTML не запускает сервер.

Адрес localhost на телефоне относится к самому телефону. Для проверки со смартфона используйте опубликованный HTTPS-сайт: обычный HTTP-адрес компьютера по Wi-Fi обычно не разрешает камеру.

## Проверка на реальной печати

Откройте сайт на смартфоне и последовательно покажите три напечатанных изображения. Проверьте соответствие аудио, громкость, перемотку и погасший индикатор камеры после перехода. Повторите при освещении и на расстоянии, которые будут у посетителей.

При ошибках проверьте HTTPS и разрешение камеры, уберите блики, покажите изображение целиком. Во встроенном браузере мессенджера лучше выбрать «Открыть в браузере». При недоступном файле проверьте путь, регистр, завершение публикации и обновите страницу.

Кадры обрабатываются в браузере. В приложении нет аналитики и отправки кадров на сервер. Библиотеки включены в проект и загружаются с того же сайта; для скачивания самого сайта нужен интернет. Офлайн-режим не реализован.
